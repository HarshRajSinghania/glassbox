## v0.8.0 — Benchmarks & PyPI

glassbox is now installable from PyPI — and this release ships the experiment that
motivated the whole tool: a 40-email benchmark asking whether a bigger, more fluent
model explains itself better, and whether a prompt can fix it when it doesn't.

### Install

```bash
pipx install glassbox-audit     # or: pip install glassbox-audit
```

The PyPI distribution is **`glassbox-audit`** (the `glassbox` name there belongs to
an unrelated project). The command and the import package are still `glassbox`.

### Headline: grounding is not faithfulness

Across 40 labelled emails on local Qwen 2.5 (3B vs 7B via Ollama):

- The **7B paraphrases its evidence** — on the plain prompt its grounding collapses
  to **48%** (the 3B holds **98%**), so more than half its citations can't even be
  located in the source.
- The new **`--prompt few-shot`** adds two worked examples of verbatim quoting. On
  the 7B it works, dramatically: grounding **48% → 80%**, accuracy **78% → 90%**,
  calibration **ECE 0.22 → 0.08**.
- **…but faithfulness barely moves (18% → 20%), so trustworthiness stays flat at
  18%.** The model now quotes *correctly*, yet erasing the quote still rarely
  changes the verdict. **few-shot buys back locatability, not faithfulness** — the
  citations got real, not load-bearing.
- On the small **3B the longer prompt backfires** (malformed output on 13 of 40).

Full tables, plus three qualitative failure modes — including a 7B that confidently
labelled a prompt-injection email *benign* at confidence 1.00 — are in
[`benchmarks/RESULTS.md`](benchmarks/RESULTS.md).

### What's new

- **`--prompt {plain,few-shot}`** on every analysis verb and the benchmark runner.
- **Benchmark suite** grown to 40 documents across 27 categories, plus **`--runs N`**
  to *measure* a model's run-to-run non-determinism (mean + min–max spread).
- **Thai / multilingual** consistency perturbations and `examples/thai.jsonl`; CLI
  output is forced to UTF-8 so non-ASCII evidence renders instead of mojibake.
- **Contributor onboarding**: `CONTRIBUTING.md`, issue/PR templates, launch drafts
  under `docs/launch/`, and a `docs/PUBLISHING.md` release guide.
- **Packaging**: ships `py.typed`, a Trusted-Publishing workflow, and richer PyPI
  metadata; `python -m build` + `twine check --strict` pass.

### Caveats

Numbers are one run per cell on a laptop GTX 1650 Ti, and the 7B is
non-deterministic run to run — treat the direction as real and the exact rates as
noisy. `--runs N` is there to firm them up.
